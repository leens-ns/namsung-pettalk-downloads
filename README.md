# 남성초 펫톡 다운로드

[펫톡 시작하기 · 설치와 사용 안내](https://namsung-pettalk.web.app/#home)

Windows 10·11 64비트용입니다. Mac에서는 실행되지 않습니다.

1. 관리자에게 본인 Google 이메일로 이용 승인을 받습니다. 계정이나 비밀번호를 공유하지 않습니다.
2. [최신 릴리즈](https://github.com/leens-ns/namsung-pettalk-downloads/releases/latest)의 `PetTalk-Setup-v…zip`을 받습니다.
3. 압축을 풀고 안의 `남성초-펫톡-설치.exe`를 실행합니다.
4. 위젯 설정에서 **Google 계정 연결 → 최초 1회 무료 AI 준비**를 진행합니다.

[단계별 매뉴얼과 문제 해결](https://namsung-pettalk.web.app/#manual)

이 저장소는 설치 파일만 공개합니다. 소스코드·학교 자료·로그인 정보는 포함하지 않습니다. 최신 설치판 하나만 제공하며 휴대용 배포는 종료했습니다. 기존 설치판 위에 설치해 업데이트할 수 있습니다.

유료 AI API 대신 각 PC의 Ollama를 사용합니다. 최초 AI 모델 다운로드와 PC 저장 공간이 필요하며 저사양 PC는 답변이 느릴 수 있습니다. 무료 클라우드 한도에 따라 자료 제공이 일시 중단될 수 있습니다. 웹은 답변 예시이며 실제 자유 질문은 Windows 펫톡에서 합니다.
